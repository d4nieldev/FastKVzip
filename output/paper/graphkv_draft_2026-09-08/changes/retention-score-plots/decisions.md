# Implementation decisions

The original fixed-axis choice in D1 and D5 is superseded by the user's zoom request in D8. D7 records the original validation; D9 records the updated validation.

- **D1 - Score and baseline.** Plot the six measured ratios at numeric x coordinates 20, 30, 40, 50, 75, and 100, with raw scores and common 0-100 ticks. Preserve each method's own measured full-cache score. Of 60 individual configurations, 36 share identical baselines and use one gray dashed reference; 24 differ and use method-colored references. Colored dashes have different phases so closely overlapping levels can be distinguished. The three measured curves remain solid. **Status: agent presentation decision, consistent with the user's earlier baseline preference.**
- **D2 - Aggregation.** The seven benchmark panels reproduce existing table aggregates from full-precision configuration scores. Categories use the same equal-configuration weighting independently at each ratio. SCBench's 11-base-task and 27-configuration means are separate; RULER summaries distinguish 4K, 8K, selected 64K, and all 33 evaluated configurations. The overall panel averages all 60 configurations, not an equal mean of benchmark means. **Status: agent decision preserving table conventions.**
- **D3 - Official groups.** Checked SCBench Section 3.1/Table 2 and RULER Section 3/Appendix B/Table 5. Include four SCBench families with and without prepared length variants, four RULER families at each evaluated length, and all available RULER needle-retrieval subtypes at each length. Group mappings, official task counts, primary-source links, and exclusions are archived in `data/retention-plot-groups.json`. **Status: source-verified implementation.**
- **D4 - Coverage limitations.** Plot all 60 matched configurations, not the 47 inventory entries without matched scores. Explicitly mark the missing Chinese-QA task in SCBench semantic retrieval, partial RULER 64K family membership, and missing 64K multi-query retrieval. Existing combined Many-shot and mixed-task scores remain combined because this table snapshot does not expose component scores. One-task categories deliberately repeat the corresponding task curve for convenient side-by-side family comparisons. **Status: agent decision based on available measurements.**
- **D5 - Organization.** Deliver 98 panels on 23 vector plot pages: 60 individual configurations and 38 grouped panels. Appendix D adds one guide page followed by those plot pages, preserving Appendix C and Figure 2 numbering. Individual task pages follow the table order, separated by benchmark and RULER context length. At most six panels per page, balanced pagination, shared legends, numbered filenames, a Markdown membership index, and 31 PDF bookmarks support navigation. **Status: agent decision.**
- **D6 - Reproducibility and dependencies.** `plot_retention_scores.py` builds the plots, appendix source, index, grouped-score snapshot, and atlas from the existing table snapshot. pypdf 6.18.1 was added only to the existing plotting environment to combine vector pages and add bookmarks. The standalone untracked paper copy uses the existing artifact workflow; no experiment, remote write, tracked-project commit, or PR is needed. Backups and original-source hashes are in `tmp/pdfs/retention-atlas-review/before`. **Status: agent decision.**
- **D7 - Validation.** Independent recomputation verified all 1,764 plotted values and 294 baseline levels, all 60 unique individual configurations, and all seven benchmark summaries against the tables. Artist inspection confirmed three solid curves per panel, actual retention coordinates, common score axes, and constant dashed references. All index links and 31 bookmark destinations work. SHA-256 checks confirm the original score snapshots, result tables, and relative context-length Figure 2 are unchanged. The paper compiled to 47 pages without LaTeX warnings; main-text pages 6-7 and all new pages 24-47 were rendered and visually inspected. **Status: completed.**
- **D8 - Zoomed y-axes.** The user requested: "the scale of the y axis in the plots is confusing and it is hard to diffrentiate between the methods. Instead do a scale that more zooms in and provides a way to see the actual differences". Replace fixed 0-100 axes with per-panel linear ranges enclosing all three curves and their full-cache baselines. Use 8% data padding, a minimum two-point window, simple absolute-score ticks within 0-100, and 5% frame padding beyond the outer ticks. Disable offsets/scientific notation and explicitly label the varying ranges on every plot page and in the appendix guide. Six constant panels are annotated "All methods: 100"; no differences are invented. This applies to the 98 retention-score panels. Archive their limits and ticks in the plot snapshot; scores, grouping, page order, and the separate context-length Figure 2 are unchanged. **Status: user-requested presentation change; detailed axis policy is an agent decision.**
- **D9 - Zoom validation.** Independent comparison confirmed that removing the new axis metadata leaves the plot snapshot identical to the prior version. All 98 ranges contain every method score and baseline; tick labels are on-canvas and do not overlap each other or neighboring panels. The median displayed window is 8.8 points instead of 106. The rebuilt paper remains 47 pages with no LaTeX warnings. All new appendix pages (24-47) were rendered and visually inspected after the scale change. **Status: completed.**
