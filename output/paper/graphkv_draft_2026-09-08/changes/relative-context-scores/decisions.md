# Implementation decisions

- **D1 — Denominator scope.** The user specified each method's own full-cache score but did not specify the aggregation scope. Use each configuration's mean full-cache score on the same contexts within each length bucket, then average task ratios with context-count weights. A ratio of pooled means would implicitly weight high-baseline tasks more; a full-configuration denominator would leave the full-cache curve varying across buckets. **Status: method-specific baseline approved by the user; bucket scope and weighting are agent decisions.**
- **D2 — Zero scores.** Individual contexts can have zero full-cache scores, so do not divide by their individual scores. All observed configuration/bucket/method means are positive (minimum 20.139). Raise an error if a future denominator is nonpositive or nonfinite; do not exclude contexts or add an arbitrary epsilon. **Status: agent decision.**
- **D3 — Presentation.** Preserve the existing six panels, context bins, context counts, colors, and method labels. The full-cache panel is now 100% by construction. Add dashed 100% references and expand the shared upper limit to include improvements above 100%; keep the zero lower bound. The caption and main text explain the normalization and remaining task-composition limitation. **Status: agent decision.**
- **D4 — Data and provenance.** Keep the raw per-context snapshot, native scoring, and absolute result tables unchanged. Save a separate derived snapshot containing the normalized curves, denominators, composition, and SHA-256 of the raw source. No evaluations or remote writes are needed. **Status: agent decision.**
- **D5 — Artifact workflow.** Inspection established that this is the standalone, untracked paper review copy documented in its README, rather than a tracked repository feature. Deliver edits in that copy and the existing `output/pdf` locations. Preserve the affected originals under `tmp/pdfs/relative-context-review/before`; no Git branch, commit, or PR is created for the unrelated tracked project. This uses the artifact workflow after initially consulting plan-to-pr. **Status: agent decision.**
- **D6 — Validation.** The plotting script checks normalization before pooling, context rather than question weighting, method-specific and bucket-specific denominators, individual zero-score inclusion, empty buckets, values above 100%, and zero-denominator rejection. The figure regenerates from all 18,531 saved contexts. The TeX Live build succeeds with 23 pages and no LaTeX warnings; pages 6 (explanation) and 21 (Figure 2) were rendered with Poppler and visually inspected. **Status: completed.**
