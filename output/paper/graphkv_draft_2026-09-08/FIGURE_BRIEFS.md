## 2. Score-gradient replay (method or appendix)

Create a left-to-right three-step schematic illustrating memory scheduling, not a benchmark. Step 1: compute scores for all independent context blocks without retaining selector activations. Step 2: compact the original KV cache and run the frozen language model's answer forward and backward passes, saving one scalar loss gradient per importance score. Step 3: replay block 1, apply its saved score gradients, release its activation graph, and repeat for blocks 2 through B. Accumulate all parameter gradients before one update.

Use a narrow timeline below the steps to show which activation graphs are live: language-model answer activations in Step 2, then one selector block at a time in Step 3. Keep persistent full-context hidden representations, original KV storage, scores, and score gradients in a separate labeled band. The figure must not imply that total memory is independent of context length, that only one block's KV cache is stored, or that context prefill and language-model backward are repeated for every block. Include the small equation “parameter gradient = sum of block Jacobian-transpose × saved score gradient.” If showing a comparison timeline, label it “schematic, not measured.”

Suggested caption: “Score-gradient replay separates language-model differentiation from selector differentiation. Global selection effects are captured in the saved score gradients; independent scorer blocks can then be recomputed and differentiated sequentially.”
